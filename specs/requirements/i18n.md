# I18N — Internationalization

Languages of the user interface and of the assistant. Background: ADR-0019.

## I18N-001: Externalized strings

- **Status:** implemented
- **Priority:** MUST
- **Phase:** 1
- **Verification:** design

Every user-facing string in clients MUST come from translation resources,
never from hard-coded text. Server responses carry stable codes that clients
translate (API-007).

## I18N-002: English and Italian

- **Status:** draft
- **Priority:** MUST
- **Phase:** 4
- **Verification:** review

The first release MUST ship complete English and Italian translations.

## I18N-003: Assistant language

- **Status:** implemented
- **Priority:** SHOULD
- **Phase:** 1
- **Verification:** integration, eval

A user MAY set a preferred language among their user defaults, and clear it.
The assistant SHOULD answer in the user's preferred language unless the user
writes in, or asks for, another one; without a preferred language, it SHOULD
answer in the language the user writes in. The preferred language MUST reach
every run of the user's conversations from their next run, whatever their
base instructions (ADR-0103).
