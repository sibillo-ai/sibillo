# I18N — Internationalization

Languages of the user interface and of the assistant. Background: ADR-0019.

## I18N-001: Externalized strings

- **Status:** implemented
- **Priority:** MUST
- **Phase:** 1
- **Verification:** design

Every user-facing string in clients MUST come from translation resources,
never from hard-coded text. Server responses carry stable codes that clients
translate (API-007).

## I18N-002: The interface in every language

- **Status:** accepted
- **Priority:** MUST
- **Phase:** 3
- **Verification:** design, e2e

The web client MUST offer its interface in every language of the list the
preferred language is chosen from (I18N-003), each from one translation
resource. The English and Italian translations MUST be complete and reviewed
by a person; the others MAY be made by a model, and MUST then be marked as
translated automatically where the user chooses a language. A translation
MUST NOT hold a key the English resource lacks, a text translated from an
English text that has changed since, or placeholders other than the English
text's; a string a translation lacks MUST be shown in English (ADR-0135).

## I18N-003: Assistant language

- **Status:** implemented
- **Priority:** SHOULD
- **Phase:** 1
- **Verification:** integration, eval

A user MAY set a preferred language among their user defaults, and clear it.
The assistant SHOULD answer in the user's preferred language unless the user
writes in, or asks for, another one; without a preferred language, it SHOULD
answer in the language the user writes in. The preferred language MUST reach
every run of the user's conversations from their next run, whatever their
base instructions (ADR-0103).

## I18N-004: The interface's language

- **Status:** accepted
- **Priority:** MUST
- **Phase:** 3
- **Verification:** e2e

The interface MUST be shown in the user's preferred language when the client
has a translation for it, otherwise in the first of the browser's languages
for which it has one, otherwise in English, matching tags by lookup
(RFC 4647). Before sign-in, the browser's languages MUST decide. A change of
the preferred language MUST change the interface at once, without reloading.
Notifications MUST be shown in the interface language (ADR-0135).

## I18N-005: Right-to-left languages

- **Status:** accepted
- **Priority:** MUST
- **Phase:** 3
- **Verification:** design, e2e

The document's language and direction MUST follow the interface language,
and in a right-to-left language the layout and the icons that point a
direction MUST mirror. The styles MUST NOT use physical left and right where
a logical property exists. Text written by the user or the assistant MUST
take its own direction, whatever the interface's (ADR-0135).

## I18N-006: Plurals, dates and numbers

- **Status:** accepted
- **Priority:** MUST
- **Phase:** 3
- **Verification:** design, e2e

Plural forms MUST follow the plural rules of the interface language, and
dates, times, numbers, sizes, durations and costs MUST be formatted by the
platform in the interface language, never by hand or in a fixed locale
(ADR-0135).
